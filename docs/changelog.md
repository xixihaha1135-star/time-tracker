## [2.0.0] - 2026-06-14

### 新增

- **类别系统与维度分析**：每条记录新增 `category` 字段，顶层新增 `categories` 字典，支持学习/生活/运动/娱乐/工作/其他六大类别的自动匹配与手动归并。告别扁平活动列表，按维度审视时间分配
- **批量记录**：支持一次输入多条活动记录，用 `、` / `+` / `，` 或换行分隔，自动逐条解析、归并、写入
- **三级日历下钻**：可视化页面新增年视图热力图 -> 月视图周统计 -> 日视图明细的三级下钻，从全年分布逐层聚焦到每分钟
- **堆叠面积图**：趋势分析新增堆叠面积图，按类别展示时间构成的演变，同一切面可对比多活动的变化趋势
- **环形图报告**：分析视图新增环形图，直观展示各类别的占比分布
- **双主题一键切换**：支持暗色（GitHub 风格，默认，护眼）和亮色（Apple Health 风格，清爽），适应不同使用场景
- **微信 AI 适配**：新增 `wechat-ai/` 目录，包含三个核心 API（recordTime / getStats / modifyRecord）和两个 UI 组件（stat-card / day-detail），为微信小程序接入做准备（当前提审中）
- **综合 README**：新增完整的项目 README，涵盖功能特性、安装指南、使用示例、数据格式、贡献指南和许可证

### 变更

- 数据格式升级：`records.json` 从 v1 升级到 v2，每条记录增加 `category` 字段，顶层增加 `categories` 字典
- v1 升级到 v2 无需脚本，手动添加 `category` 和 `categories` 字段即可
- SKILL.md 全面重写，新增批量解析、类别管理、连续性分析等功能的完整指令

### 修复

- 非今日记录的日期筛选逻辑修正：补录过去时间时，日期使用用户指定的日期而非当天

## [1.0.0] - 2026-06-10

### 新增

- **自然语言记录**：用一句话完成时间记录，如「看书半小时」「写代码2h」，无需打开任何 App 或手动填表
- **别名归并**：智能识别同一活动的不同表述（如"打球"自动归并到"打篮球"），保持数据一致性
- **自动类别分配**：新活动自动匹配已有类别，未匹配的放入「其他」并引导用户归类
- **单日历热力图**：年度日历视图，颜色深度反映时间投入量
- **趋势折线图**：按活动跟踪时间投入趋势，支持 30 天 / 90 天 / 365 天切换，支持缩放与拖拽
- **文字统计报告**：按总览、类别分布、活动排名三个维度输出时间报告，支持今日/昨日/本周/本月/上周/上月查询
- **环比对比**：查询上周/上月时自动与上一周期对比，呈现各类别的增减变化
- **连续性分析**：自动计算当前连续记录天数和历史最长连续天数
- **记录修改与删除**：支持修改时长、活动名、类别，支持删除记录（需二次确认，防止误删）
- **自动 Git 提交**：每次记录修改后自动提交，实现数据版本管理与备份
- **跨平台数据迁移**：所有数据存储在单文件 `records.json` 中，复制即可跨平台迁移
