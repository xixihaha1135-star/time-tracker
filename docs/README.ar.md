# Time Tracker ⏱

> الوقت هو موردك الأساسي — أين تنفقه يحدد من تصبح.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-brightgreen)](https://xixihaha1135-star.github.io/time-tracker/)

مهارة (Skill) لتتبع الوقت متعددة المنصات. تخبر الـ Agent بما فعلته وكم من الوقت استغرقت باستخدام اللغة الطبيعية، فيقوم تلقائيًا بالتسجيل والدمج تحت أسماء موحدة وإنشاء تقارير مرئية.

**Live Demo**: https://xixihaha1135-star.github.io/time-tracker/

---

## الميزات

- **تسجيل باللغة الطبيعية، بدون عوائق** — قل "قراءة كتاب نصف ساعة" ويتم التسجيل، لا حاجة لفتح أي تطبيق أو ملء نماذج يدويًا
- **دمج ذكي للأسماء المستعارة + تصنيف تلقائي للفئات** — "لعب كرة" يُدمج تلقائيًا إلى "لعب كرة السلة"، والأنشطة تُصنف تلقائيًا إلى خمس فئات: الدراسة / التمارين / الحياة اليومية / الترفيه / العمل
- **تقويم ثلاثي المستويات مع استكشاف تفصيلي + لوحة معلومات مرئية** — عرض سنوي بخريطة حرارية، إحصائيات أسبوعية بالعرض الشهري، تفاصيل يومية، مع استكشاف تفصيلي تدريجي لمعرفة أين يذهب وقتك بوضوح
- **تبديل بين وضعين بنقرة واحدة** — الوضع الداكن بأسلوب GitHub (مريح للعين) / الوضع الفاتح بأسلوب Apple Health (منعش)، ليناسب مختلف سيناريوهات الاستخدام
- **بياناتك ملكك بالكامل** — جميع السجلات محفوظة في ملف `records.json` واحد، يمكنك نقله بين الأجهزة والمنصات والـ Agents بمجرد النسخ واللصق
- **متعدد المنصات** — نفس ملف `SKILL.md` يعمل مع Claude Code / Cursor / Coze (扣子) / Feishu (飞书) / أي AI Agent عام

## البداية السريعة

### الطريقة الأولى: Claude Code (موصى بها)

```bash
# 1. استنساخ المستودع
git clone https://github.com/xixihaha1135-star/time-tracker.git

# 2. نسخ SKILL.md إلى مشروعك
mkdir -p مشروعك/.claude/skills/time-tracker
cp time-tracker/SKILL.md مشروعك/.claude/skills/time-tracker/

# 3. نسخ صفحة العرض المرئي وملف البيانات أيضًا
cp time-tracker/index.html مشروعك/.claude/skills/time-tracker/
cp time-tracker/records.json مشروعك/.claude/skills/time-tracker/
```

بعد التثبيت، تحدث إلى Claude Code مباشرة:

- «قراءة كتاب نصف ساعة» → تسجيل تلقائي
- «عرض الإحصائيات» → إنشاء تقرير نصي
- «فتح إحصائيات الوقت» → فتح صفحة العرض المرئي

### الطريقة الثانية: Cursor / Copilot / أي AI IDE عام

1. افتح `SKILL.md` وانسخ المحتوى بالكامل
2. الصقه في ملف `.cursorrules` أو `copilot-instructions.md` أو ملف تعليمات الـ Agent في مشروعك
3. ضع `records.json` في المجلد الجذري للمشروع، و `index.html` في موقع يمكن الوصول إليه

### الطريقة الثالثة: Coze (扣子) / Feishu (飞书) / أي Agent عام

1. افتح `SKILL.md` وانسخ المحتوى بالكامل
2. الصقه في **System Prompt (الموجه النظامي)** للـ Agent الخاص بك
3. ارفع `records.json` كملف قاعدة معرفة، أو الصق محتواه مباشرة
4. ابدأ المحادثة وسجل وقتك

## أمثلة الاستخدام

### تسجيل الوقت

```
أنت: قراءة كتاب نصف ساعة
Agent: تم التسجيل: قراءة كتاب 30 دقيقة (الدراسة) ✅  تم تسجيل 1 سجل اليوم، بإجمالي 30 دقيقة.
```

### تسجيل مجمع

```
أنت: قراءة كتاب نصف ساعة، لعب ألعاب 20 دقيقة، تناول طعام 30 دقيقة
Agent: تم تسجيل 3 سجلات، بإجمالي 80 دقيقة ✅
      - قراءة كتاب 30 دقيقة (الدراسة)
      - لعب ألعاب 20 دقيقة (الترفيه)
      - تناول طعام 30 دقيقة (الحياة اليومية)
      تم تسجيل 3 سجلات اليوم، بإجمالي 80 دقيقة.
```

### عرض الإحصائيات

```
أنت: اليوم
Agent: 📊 تقرير وقت اليوم (6.14)
      إجمالي السجلات: 4 | إجمالي الوقت: 3 ساعات و 30 دقيقة
      📂 توزيع الفئات:
      1. الدراسة — 2س (57%)
      2. الحياة اليومية — 1س (29%)
      3. التمارين — 30د (14%)

أنت: هذا الأسبوع
Agent: 📊 تقرير وقت الأسبوع (6.9 - 6.14)
      إجمالي السجلات: 31 | إجمالي الوقت: 18 ساعة و 45 دقيقة
      📂 توزيع الفئات:
      1. الدراسة — 8س30د (45%)
      2. العمل — 5س (27%)
      3. الحياة اليومية — 3س (16%)
      4. التمارين — 1س45د (9%)
      5. الترفيه — 30د (3%)
      📋 ترتيب الأنشطة:
      1. التحضير لـ CET-6 — 6س
      2. بحث تقنيات AI — 2س30د
      3. الحساب العام — 2س
      ...
```

### دمج الأسماء المستعارة

```
أنت: ادمج لعب كرة إلى لعب كرة السلة
Agent: تم دمج «لعب كرة» إلى «لعب كرة السلة». تم تحديث 3 سجلات سابقة.
```

### تعديل سجل

```
أنت: السجل السابق كان خطأ، في الحقيقة كان ساعة واحدة
Agent: تم التعديل: بحث تقنيات AI 60 دقيقة ✅ (كانت 30 دقيقة)
```

### حذف سجل

```
أنت: احذف السجل الأخير
Agent: هل أنت متأكد من حذف «التحضير لـ CET-6 60 دقيقة» (الدراسة)؟
أنت: نعم
Agent: تم الحذف ✅
```

## العرض المرئي

يعرض الـ Demo المباشر ثلاث طرق عرض، البيانات من `records.json`، يتم تحميل الصفحة من نفس المجلد مباشرة:

| العرض | الوصف |
|------|------|
| **خريطة حرارية سنوية** | شبكة تقويم 365 يومًا، كلما كان اللون أغمق زاد الوقت المستثمر، انقر على أي يوم لعرض جميع سجلاته |
| **مخطط خطي للاتجاهات** | مقارنة اتجاهات الوقت المستثمر حسب النشاط/الفئة، مع إمكانية التبديل بين 30 يومًا / 90 يومًا / 365 يومًا، ودعم التكبير والسحب |
| **تقرير تحليلي** | ترتيب الأنشطة، توزيع الفئات، التغير النسبي، المتوسط اليومي، أكبر بند استهلاك، إنشاء ملخص نصي بنقرة واحدة |

يدعم **وضعين**: تبديل بنقرة واحدة في الزاوية اليمنى العليا بين الوضع الداكن (أسلوب GitHub، افتراضي) والوضع الفاتح (أسلوب Apple Health).

> صفحة العرض المرئي الكاملة: https://xixihaha1135-star.github.io/time-tracker/

## تنسيق البيانات

جميع السجلات محفوظة في `records.json`، بهيكل الإصدار v2 كالتالي:

```json
{
  "version": "2.0",
  "aliases": {
    "قراءة كتب إنجليزية أصلية": "قراءة كتاب",
    "كتابة كود بالذكاء الاصطناعي": "بحث تقنيات AI"
  },
  "records": [
    {
      "id": "20260610-182449-fc55",
      "date": "2026-06-10",
      "start": "",
      "end": "",
      "duration_min": 30,
      "activity": "قراءة كتاب",
      "raw_input": "قراءة كتاب نصف ساعة",
      "created_at": "2026-06-10T18:24:49.079383Z",
      "category": "الدراسة"
    }
  ],
  "categories": {
    "الدراسة": ["قراءة كتاب", "عمل الواجبات", "التحضير لـ CET-6"],
    "الحياة اليومية": ["تناول طعام", "غسيل واستحمام", "استراحة"],
    "التمارين": ["تدريب صباحي", "لياقة بدنية"],
    "الترفيه": ["تصفح الهاتف", "لعب ألعاب"],
    "العمل": ["بحث تقنيات AI", "الحساب العام", "اجتماعات", "عمل"]
  }
}
```

**وصف الحقول:**

| الحقل | النوع | الوصف |
|------|------|------|
| `version` | string | إصدار تنسيق البيانات، حاليًا `"2.0"` |
| `aliases` | object | جدول تعيين الأسماء المستعارة، المفتاح هو اسم النشاط الذي أدخله المستخدم، والقيمة هي الاسم الموحد |
| `records[].id` | string | معرّف فريد، بالتنسيق `YYYYMMDD-HHmmss-xxxx` |
| `records[].date` | string | تاريخ السجل، بالتنسيق `YYYY-MM-DD` |
| `records[].start` | string | وقت البدء (اختياري)، بالتنسيق `HH:mm` |
| `records[].end` | string | وقت الانتهاء (اختياري)، بالتنسيق `HH:mm` |
| `records[].duration_min` | number | المدة بالدقائق |
| `records[].activity` | string | اسم النشاط الموحد (بعد دمج الأسماء المستعارة) |
| `records[].raw_input` | string | الإدخال الأصلي للمستخدم، للاحتفاظ بالمصدر |
| `records[].created_at` | string | وقت إنشاء السجل، بتنسيق ISO 8601 |
| `records[].category` | string | الفئة المنتمي إليها (الدراسة/الحياة اليومية/التمارين/الترفيه/العمل/أخرى) |
| `categories` | object | قاموس الفئات، المفتاح هو اسم الفئة، والقيمة هي مصفوفة بأسماء الأنشطة في تلك الفئة |

**التصنيف التلقائي**: عند تسجيل نشاط جديد، يتصفح الـ Agent قاموس `categories` للعثور على الفئة المطابقة؛ ما لا يطابق يوضع في «أخرى»، ويُسأل المستخدم عن الفئة التي يريدها.

**الترحيل من v1 إلى v2**: مقارنة بـ v1، أضاف v2 حقل `category` لكل سجل، وقاموس `categories` في المستوى الأعلى. للترقية من v1، فقط أضف هذين الحقلين يدويًا، لا حاجة لأي سكريبت.

## ترحيل البيانات

**مبدأ التصميم**: البيانات تتبعك، غير مرتبطة بأي منصة.

### التصدير

انسخ `records.json` فقط. ملف واحد يحتوي على جميع سجلات وقتك، وتعيينات الأسماء المستعارة، وإعدادات الفئات.

```bash
# نسخ احتياطي إلى أي موقع
cp records.json ~/backup/records-$(date +%Y%m%d).json
```

### الاستيراد

ضع `records.json` في المجلد الجذري للمشروع في البيئة الجديدة (أو أي مسار يمكن لـ SKILL.md اكتشافه)، وسيتعرف عليه الـ Agent تلقائيًا ويواصل التسجيل.

### عبر المنصات

نفس ملف `records.json` متطابق تمامًا في التنسيق عبر Claude Code و Cursor و Coze (扣子) و Feishu (飞书) وجميع المنصات، لا حاجة لأي تحويل.
