# Time Tracker ⏱

> Время — ваш главный ресурс — куда вы его тратите, тем вы и становитесь.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-brightgreen)](https://xixihaha1135-star.github.io/time-tracker/)

Кроссплатформенный Skill для учёта времени. Вы говорите агенту на естественном языке, что делали и сколько времени потратили, а он автоматически записывает, объединяет по псевдонимам, распределяет по категориям и генерирует визуальные отчёты.

**Live Demo**: https://xixihaha1135-star.github.io/time-tracker/

---

## Возможности

- **Ввод на естественном языке, без порога входа** — скажите «читал полчаса», и запись готова. Не нужно открывать приложение, не нужно заполнять формы вручную
- **Умное объединение псевдонимов + автоматическая категоризация** — «играл в мяч» автоматически объединяется с «играл в баскетбол», а занятия распределяются по пяти категориям: Учёба, Спорт, Повседневная жизнь, Развлечения, Работа
- **Трёхуровневая календарная детализация + визуальная панель** — тепловая карта за год, недельная статистика по месяцам, детализация по дням. Спускайтесь на уровень ниже — и сразу видно, куда уходит время
- **Две темы в один клик** — тёмная тема в стиле GitHub (щадящая для глаз) / светлая тема в стиле Apple Health (чистая и свежая), под любые сценарии
- **Все данные — ваши** — все записи хранятся в одном файле `records.json`. Меняете компьютер, платформу, агента — скопируйте файл, и всё с вами
- **Кроссплатформенность** — один и тот же SKILL.md работает с Claude Code / Cursor / Coze / Feishu / любым AI-агентом

## Быстрый старт

### Способ 1: Claude Code (рекомендуется)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/xixihaha1135-star/time-tracker.git

# 2. Скопируйте SKILL.md в свой проект
mkdir -p ваш-проект/.claude/skills/time-tracker
cp time-tracker/SKILL.md ваш-проект/.claude/skills/time-tracker/

# 3. Скопируйте страницу визуализации и файл данных
cp time-tracker/index.html ваш-проект/.claude/skills/time-tracker/
cp time-tracker/records.json ваш-проект/.claude/skills/time-tracker/
```

После установки просто скажите Claude Code:

- «читал полчаса» → автоматическая запись
- «покажи статистику» → текстовый отчёт
- «открой статистику времени» → страница визуализации

### Способ 2: Cursor / Copilot / универсальные AI IDE

1. Откройте `SKILL.md`, скопируйте всё содержимое
2. Вставьте в ваш `.cursorrules`, `copilot-instructions.md` или файл инструкций агента проекта
3. Поместите `records.json` в корень проекта, `index.html` — в доступное расположение

### Способ 3: Coze / Feishu / универсальный агент

1. Откройте `SKILL.md`, скопируйте всё содержимое
2. Вставьте в **System Prompt (системный промпт)** вашего агента
3. Загрузите `records.json` как файл базы знаний или вставьте его содержимое
4. Начинайте диалог и записывайте время

## Примеры использования

### Запись времени

```
Вы: читал полчаса
Агент: Записано: чтение 30 мин (Учёба) ✅  Сегодня 1 запись, всего 30 мин.
```

### Пакетная запись

```
Вы: читал полчаса, играл 20 минут, ел 30 минут
Агент: Записано 3 записи, всего 80 мин ✅
       - чтение 30 мин (Учёба)
       - игры 20 мин (Развлечения)
       - еда 30 мин (Повседневная жизнь)
       Сегодня 3 записи, всего 80 мин.
```

### Просмотр статистики

```
Вы: сегодня
Агент: 📊 Отчёт за сегодня (14.06)
       Всего записей: 4 | Всего времени: 3 ч 30 мин
       📂 По категориям:
       1. Учёба — 2 ч (57%)
       2. Повседневная жизнь — 1 ч (29%)
       3. Спорт — 30 мин (14%)

Вы: эта неделя
Агент: 📊 Отчёт за неделю (9.06 - 14.06)
       Всего записей: 31 | Всего времени: 18 ч 45 мин
       📂 По категориям:
       1. Учёба — 8 ч 30 мин (45%)
       2. Работа — 5 ч (27%)
       3. Повседневная жизнь — 3 ч (16%)
       4. Спорт — 1 ч 45 мин (9%)
       5. Развлечения — 30 мин (3%)
       📋 Рейтинг занятий:
       1. Подготовка к CET-6 — 6 ч
       2. Исследование AI — 2 ч 30 мин
       3. Блог — 2 ч
       ...
```

### Объединение псевдонимов

```
Вы: объедини «играл в мяч» с «играл в баскетбол»
Агент: «играл в мяч» объединён с «играл в баскетбол». Обновлено 3 старых записи.
```

### Редактирование записи

```
Вы: я ошибся, на самом деле час
Агент: Изменено: Исследование AI 60 мин ✅ (было 30 мин)
```

### Удаление записи

```
Вы: удали последнюю запись
Агент: Удалить «Подготовка к CET-6 60 мин» (Учёба)?
Вы: да
Агент: Удалено ✅
```

## Визуализация

Онлайн-демо показывает три вида представлений, данные загружаются из `records.json` в той же директории:

| Представление | Описание |
|------|------|
| **Годовая тепловая карта** | Календарная сетка на 365 дней. Чем темнее цвет, тем больше времени потрачено. Нажмите на день — увидите все записи за него |
| **График трендов** | Сравнение затрат времени по занятиям/категориям. Переключение 30 / 90 / 365 дней, поддержка масштабирования и перетаскивания |
| **Аналитический отчёт** | Рейтинг занятий, распределение по категориям, динамика изменений, среднее за день, самая затратная активность. Текстовая сводка в один клик |

Поддержка **двух тем**: переключатель в правом верхнем углу — тёмная (стиль GitHub, по умолчанию) и светлая (стиль Apple Health).

> Полная страница визуализации: https://xixihaha1135-star.github.io/time-tracker/

## Формат данных

Все записи хранятся в `records.json`, структура v2:

```json
{
  "version": "2.0",
  "aliases": {
    "читаю на английском": "чтение",
    "пишу код с AI": "Исследование AI"
  },
  "records": [
    {
      "id": "20260610-182449-fc55",
      "date": "2026-06-10",
      "start": "",
      "end": "",
      "duration_min": 30,
      "activity": "чтение",
      "raw_input": "читал полчаса",
      "created_at": "2026-06-10T18:24:49.079383Z",
      "category": "Учёба"
    }
  ],
  "categories": {
    "Учёба": ["чтение", "домашнее задание", "подготовка к CET-6"],
    "Повседневная жизнь": ["еда", "стирка", "отдых"],
    "Спорт": ["утренняя тренировка", "фитнес"],
    "Развлечения": ["телефон", "игры"],
    "Работа": ["Исследование AI", "блог", "совещания", "работа"]
  }
}
```

**Описание полей:**

| Поле | Тип | Описание |
|------|------|------|
| `version` | string | Версия формата данных, сейчас `"2.0"` |
| `aliases` | object | Карта псевдонимов: ключ — введённое пользователем название, значение — стандартное название |
| `records[].id` | string | Уникальный идентификатор, формат `YYYYMMDD-HHmmss-xxxx` |
| `records[].date` | string | Дата записи, формат `YYYY-MM-DD` |
| `records[].start` | string | Время начала (опционально), формат `HH:mm` |
| `records[].end` | string | Время окончания (опционально), формат `HH:mm` |
| `records[].duration_min` | number | Длительность в минутах |
| `records[].activity` | string | Стандартное название занятия (после объединения псевдонимов) |
| `records[].raw_input` | string | Исходный ввод пользователя, для отслеживания |
| `records[].created_at` | string | Время создания записи, формат ISO 8601 |
| `records[].category` | string | Категория (Учёба/Повседневная жизнь/Спорт/Развлечения/Работа/Другое) |
| `categories` | object | Словарь категорий: ключ — название категории, значение — массив названий занятий в ней |

**Автоматическое назначение категории**: при записи нового занятия агент проходит по словарю `categories` в поисках совпадения; если совпадений нет — помещает в «Другое» и спрашивает пользователя о категории.

**Миграция с v1 на v2**: в v2 у каждой записи появилось поле `category`, а на верхнем уровне — словарь `categories`. Для перехода с v1 достаточно вручную добавить эти два поля, скрипты не нужны.

## Миграция данных

**Принцип**: данные следуют за вами, не привязаны ни к какой платформе.

### Экспорт

Скопируйте `records.json`. Один файл содержит все ваши записи времени, карту псевдонимов и настройки категорий.

```bash
# Резервная копия в любое место
cp records.json ~/backup/records-$(date +%Y%m%d).json
```

### Импорт

Поместите `records.json` в корень проекта в новой среде (или в путь, доступный для SKILL.md), и агент автоматически распознает его и продолжит запись.

### Кроссплатформенность

Один и тот же `records.json` имеет полностью одинаковый формат на всех платформах — Claude Code, Cursor, Coze, Feishu и других. Конвертация не требуется.
