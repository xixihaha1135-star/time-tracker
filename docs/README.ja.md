# Time Tracker ⏱

> 時間は最も核心的な生産資源——どこに使うかが、あなたが誰になるかを決める。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-brightgreen)](https://xixihaha1135-star.github.io/time-tracker/)

クロスプラットフォームの時間記録 Skill です。Agent に自然言語で何をしたか、どれだけ時間を使ったかを伝えるだけで、自動的に記録、マージ/エイリアス分類、可視化レポートを生成します。

**Live Demo**: https://xixihaha1135-star.github.io/time-tracker/

---

## 機能

- **自然言語で記録、ゼロハードル** — 「読書30分」と一言伝えるだけで記録完了。アプリを開く必要も、手動でフォームに入力する必要もありません
- **スマートエイリアスマージ + カテゴリ自動分類** — 「球技」は自動で「バスケットボール」にマージ、アクティビティは学習/運動/生活/娯楽/仕事の5カテゴリに自動分類
- **3段階カレンダードリルダウン + 可視化ダッシュボード** — 年次ヒートマップ、月次週間統計、日次明細、段階的にドリルダウンし、時間の使い方が一目でわかります
- **デュアルテーマワンクリック切替** — ダーク GitHub スタイル（目に優しい）/ ライト Apple Health スタイル（クリーン）、さまざまなシーンに対応
- **データはすべてあなたのもの** — すべての記録は単一の `records.json` ファイルに保存され、PCを変えても、プラットフォームを変えても、Agent を変えても、コピー＆ペーストで持ち運べます
- **マルチプラットフォーム対応** — 同一の SKILL.md で Claude Code / Cursor / 扣子（Coze）/ 飛書（Lark）/ 汎用 AI Agent に対応
- **日記レベルの詳細記録** — 記録時に具体的な詳細（書名、ゲーム名など）を自動抽出し、振り返った時に何をしていたか思い出せます

## クイックスタート

### 方式1：Claude Code（推奨）

```bash
# 1. リポジトリをクローン
git clone https://github.com/xixihaha1135-star/time-tracker.git

# 2. SKILL.md をプロジェクトにコピー
mkdir -p あなたのプロジェクト/.claude/skills/time-tracker
cp time-tracker/SKILL.md あなたのプロジェクト/.claude/skills/time-tracker/

# 3. 可視化ページをコピー
cp time-tracker/index.html あなたのプロジェクト/.claude/skills/time-tracker/

# records.json は初回使用時に自動作成されます
```

インストール後、Claude Code に直接話しかけるだけです：

- 「読書30分」→ 自動記録
- 「統計を見る」→ テキストレポート生成
- 「時間統計を開く」→ 可視化ページを開く

### 方式2：Cursor / Copilot / 汎用 AI IDE

1. `SKILL.md` を開き、全内容をコピー
2. `.cursorrules`、`copilot-instructions.md`、またはプロジェクトの agent 指示ファイルに貼り付け
3. `index.html` をアクセス可能な場所に配置。エージェントに「時間を記録」と言うと、初回使用時に `records.json` を自動作成します（データ形式は `records.example.json` を参照）

### 方式3：扣子（Coze）/ 飛書 / 汎用 Agent

1. `SKILL.md` を開き、全内容をコピー
2. あなたのエージェントの **System Prompt（システムプロンプト）** に貼り付け
3. `records.example.json` をナレッジベースファイルとしてアップロード（データ形式の参考）。エージェントが初回使用時に `records.json` を自動作成します
4. 会話を開始して記録

## 使用例

### 時間の記録

```
あなた：読書30分
Agent：記録しました：読書 30分（学習）✅  本日 1 件記録、合計 30 分。
```

### 一括記録

```
あなた：読書30分、ゲーム20分、食事30分
Agent：3 件記録しました、合計 80 分 ✅
      - 読書 30分（学習）
      - ゲーム 20分（娯楽）
      - 食事 30分（生活）
      本日 3 件記録、合計 80 分。
```

### 詳細付き記録

```
あなた：「時間を味方につける」を30分読んだ
Agent：記録しました：読書（時間を味方につける）30分（学習）✅  本日 1 件記録、合計 30 分。
```

### 統計の確認

```
あなた：今日
Agent：📊 本日の時間レポート（6.14）
      総記録：4 件 | 総投入：3 時間 30 分
      📂 カテゴリ分布：
      1. 学習 — 2h（57%）
      2. 生活 — 1h（29%）
      3. 運動 — 30min（14%）

あなた：今週
Agent：📊 今週の時間レポート（6.9 - 6.14）
      総記録：31 件 | 総投入：18 時間 45 分
      📂 カテゴリ分布：
      1. 学習 — 8h30m（45%）
      2. 仕事 — 5h（27%）
      3. 生活 — 3h（16%）
      4. 運動 — 1h45m（9%）
      5. 娯楽 — 30m（3%）
      📋 アクティビティランキング：
      1. 六級試験対策 — 6h
      2. AI技術研究 — 2h30m
      3. 公式アカウント — 2h
      ...
```

### エイリアスマージ

```
あなた：球技 を バスケットボール にマージ
Agent：「球技」を「バスケットボール」にマージしました。3 件の履歴記録を更新しました。
```

```
あなた：さっきの記録、間違えた、実際は1時間
Agent：修正しました：AI技術研究 60分 ✅（元 30 分）
```

```
あなた：さっきのを削除

Agent：削除しました ✅
```

## データ形式

すべての記録は `records.json` に保存されます。v2 構造は以下の通りです：

```json
{
  "version": "2.0",
  "aliases": {
    "英語原著を読む": "読書",
    "AIでコードを書く": "AI技術研究"
  },
  "records": [
    {
      "id": "20260610-182449-fc55",
      "date": "2026-06-10",
      "start": "",
      "end": "",
      "duration_min": 30,
      "activity": "読書",
      "raw_input": "読書30分",
      "created_at": "2026-06-10T18:24:49.079383Z",
      "category": "学習"
    }
  ],
  "categories": {
    "学習": ["読書", "宿題", "六級試験対策"],
    "生活": ["食事", "洗濯", "休憩"],
    "運動": ["朝練", "ジム"],
    "娯楽": ["スマホ", "ゲーム"],
    "仕事": ["AI技術研究", "公式アカウント", "会議", "仕事"]
  }
}
```

**フィールド説明：**

| フィールド | 型 | 説明 |
|------|------|------|
| `version` | string | データ形式バージョン、現在は `"2.0"` |
| `aliases` | object | エイリアスマッピングテーブル、key はユーザー入力のアクティビティ名、value は標準アクティビティ名 |
| `records[].id` | string | 一意識別子、形式 `YYYYMMDD-HHmmss-xxxx` |
| `records[].date` | string | 記録日付、形式 `YYYY-MM-DD` |
| `records[].start` | string | 開始時間（オプション）、形式 `HH:mm` |
| `records[].end` | string | 終了時間（オプション）、形式 `HH:mm` |
| `records[].duration_min` | number | 時間長、単位は分 |
| `records[].activity` | string | 標準アクティビティ名（エイリアスマージ後） |
| `records[].raw_input` | string | ユーザーの元の入力、トレーサビリティのために保持 |
| `records[].created_at` | string | 記録作成時刻、ISO 8601 形式 |
| `records[].category` | string | 所属カテゴリ（学習/生活/運動/娯楽/仕事/その他） |
| `categories` | object | カテゴリ辞書、key はカテゴリ名、value はそのカテゴリに属するアクティビティ名の配列 |

**カテゴリ自動割り当て**：新規アクティビティ記録時、Agent は `categories` 辞書を走査して一致するカテゴリを検索します。一致しないものは「その他」に入れ、ユーザーに分類の意向を確認します。

**v1 から v2 への移行**：v2 は v1 と比較して、各 record に `category` フィールドが追加され、トップレベルに `categories` 辞書が追加されています。v1 からアップグレードするには、この2つのフィールドを手動で追加するだけで済み、スクリプトは不要です。

## データ移行

**設計原則**：データはあなたに従い、どのプラットフォームにも縛られません。

### エクスポート

`records.json` をコピーするだけです。この1つのファイルに、あなたの全時間記録、エイリアスマッピング、カテゴリ設定が含まれています。

```bash
# 任意の場所にバックアップ
cp records.json ~/backup/records-$(date +%Y%m%d).json
```

### インポート

`records.json` を新しい環境のプロジェクトルート（または SKILL.md が検出できるパス）に配置すれば、Agent が自動的に認識して記録を続行します。

### クロスプラットフォーム

同一の `records.json` が Claude Code、Cursor、扣子、飛書などすべてのプラットフォームで完全に互換性のある形式で、変換は不要です。

### クロスプラットフォーム移行

```
あなた：データをエクスポートして
Agent：📦 データのエクスポートが完了しました
      [完全な JSON 内容]
      使い方：JSON をコピーし、新しいプラットフォームで「データをインポートして」と言って貼り付けます
```
